# Personal IDS & Security Monitoring Project

This is my personal project where I am building a lightweight Intrusion Detection System using my own devices.

The main goal is to learn how security monitoring works by creating the system myself. It captures network traffic, analyzes it with Python, uses rules that I wrote, and creates alerts when suspicious activity is detected.

I started this project to improve my hands-on cybersecurity skills and better understand how SOC and security analyst workflows operate in a real environment. By building this system, I am gaining practical experience in network security, detection engineering, and system design, while developing a deeper understanding of how IDS and SIEM systems work—preparing me for a security analyst role.
